Privacy Policy — Tech Shot

Effective date: 23 November 2026  |  Last updated: 23 November 2026

1. Who we are

Tech Shot is a personal automation tool built and operated by its owner ("the owner", contact: gahrwala@gmail.com). It creates short Hindi tech-news videos and publishes them to the owner's own Instagram account, Facebook Page, and YouTube channel. The app serves only the owner; it has no other users.

2. Data we collect

The app accesses and stores only the following, all belonging to the owner:

  • Account access tokens for the owner's Instagram (Graph API), Facebook Page, and YouTube (Data API v3) accounts. These are stored only as encrypted secrets in the owner's private GitHub repository and are used solely to publish the owner's content.
  • Video files, captions, and hashtags the owner creates for publication.
  • Public tech-news headlines from RSS feeds and official blogs, used only to draft video scripts.
  • The owner's email address (gahrwala@gmail.com), used as the contact and account-recovery address for the owner's own accounts.

The app does not collect, store, or process personal data of any other person. It does not collect location data, contacts, browsing history, device identifiers, or any data from visitors to this website. This website sets no cookies and runs no analytics or tracking scripts.

3. How we use the data

  • Access tokens are used for one purpose only: publishing the owner's own videos to the owner's own Instagram, Facebook Page, and YouTube channel, and only after the owner manually reviews and approves each video.
  • News headlines are used only to draft scripts. A story that cannot be verified against its original source (and a second source for major stories) is never published.
  • Video files and captions are used only to create and publish the owner's videos.
  • We do not use any data for advertising, profiling, or any purpose other than the publishing described above.

4. Data sharing

We do not sell, rent, or share personal data with any third party. The only external services that receive data are the platforms themselves, and only to carry out the owner's own publishing:

  • Meta (Instagram / Facebook) — receives the video file, caption, and hashtags when the owner approves publishing a Reel.
  • Google / YouTube — receives the video file, title, and description when the owner approves uploading a Short.
  • GitHub — hosts the app's source code and stores the owner's access tokens as repository secrets.

No other company or person receives any data from this app.

5. Data retention and deletion

Tokens and drafts live only in the owner's GitHub repository secrets and the owner's own systems. Access tokens remain valid until the owner revokes them; the owner can revoke any token at any time from the relevant platform (Meta account settings or Google account permissions), which immediately stops the app's access. Published videos remain on the owner's own social accounts until the owner deletes them there. This website stores no visitor data, so there is nothing to delete from it.

6. Your rights

Because the app has no users other than the owner and collects no data from the public, there is no personal data of visitors to access, correct, or delete. If you believe the app holds any of your data, contact the owner at the email below and it will be reviewed and deleted on request.

7. Children's privacy

Tech Shot is not directed at children, and it knowingly collects no data from anyone under 18.

8. Security

Access tokens are stored only as GitHub repository secrets (never in source code or chat), and publishing requires the owner's manual approval for every video. No data is transmitted except to Meta, Google/YouTube, and GitHub as described in section 4.

9. Changes to this policy

If this policy changes, the new version will be posted on this page with a new "Last updated" date.

10. Contact

For any question about this policy or the app, contact the owner: gahrwala@gmail.com.
