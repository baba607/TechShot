# Privacy Policy — Tech Shot

**Effective date:** 23 November 2026

Tech Shot is a personal automation tool owned and operated by its owner for
publishing the owner's own Hindi tech-news videos (Reels / Shorts) to the
owner's own Instagram, Facebook Page, and YouTube channel.

## What data the app accesses

- The owner's own account credentials and access tokens (Instagram Graph API,
  Facebook Page, YouTube Data API), stored only as secrets in the owner's
  private GitHub repository and used solely to publish the owner's content.
- Video files, captions, and hashtags the owner creates for publication.
- Public tech-news headlines from RSS feeds and official blogs, used only to
  draft video scripts.

## What we do with it

- Content is published only to the owner's own accounts, only after the
  owner's manual approval. Nothing is published automatically.
- We do **not** sell, rent, or share any personal data with third parties.
  The only external services that receive data are the platforms themselves
  (Meta / YouTube), solely to publish the owner's own videos.
- We do **not** collect data from any other person. No analytics, no tracking,
  no advertising.

## Data retention and deletion

- Tokens and drafts live only in the owner's GitHub repository secrets and the
  owner's own systems. The owner can revoke any token at any time from the
  relevant platform (Meta / Google), which immediately stops the app's access.
- To request deletion of any data held by this app, contact the owner below.
